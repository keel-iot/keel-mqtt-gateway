# 0.3.4

## Fixes

- Wait for Raft to identify the Redis primary, and redirect the Redis router to
  that node before initializing the MQTT broker on clustered broker nodes.
  This prevents an edge from trying to migrate legacy session keys on its
  bootstrap Redis replica and failing startup with `READONLY`.

The existing Redis schema marker and session data are unchanged by this fix.
`REDIS_IFM_SCHEMA=auto` continues to follow the configured schema behavior; it
does not activate the separate IFM schema 2 transition.

# v0.3.1 — Dependency and container security updates

Updates gateway dependencies and container bases, retaining the Redis read
optimizations and configurable backlog from [v0.3.0](0.3.0.md).

## Changes

- Go 1.26.10 across the main module and both local replacement modules;
  Docker builder pinned to `golang:1.26.10-alpine3.24` and gateway runtime
  updated from Alpine 3.20 to Alpine 3.24.3.
- gRPC 1.85.0, pgx 5.11.0, chi 5.5.0, OpenTelemetry 1.47.0,
  go-redis 9.23.0, current x/crypto, x/net and x/text releases, and updated
  compression dependencies. These address reported dependency advisories.
- Updated compatible filesystem, PROXY protocol, metrics, synchronization,
  protobuf, Kafka client and testing dependencies. bbolt stays on the 1.3
  patch line (1.3.12); Raft and memberlist versions are unchanged.
- Redis pinned to `7.4.12-alpine` in the chart, Compose and test environments.
  This is a patch update on Redis 7.4; Redis 8 is not introduced.
- CI runs pinned `govulncheck@v1.3.0` against the main module.
- Three fork HTTP listener tests wait for the asynchronous server to become
  available before sending requests. Production listener code and the local
  Mochi MQTT patches are preserved.

## Validation and security findings

- Go build, vet and complete main-module test suite.
- Complete test suites and vulnerability scans for both nested modules.
- Live Redis 7.4.12 storage/routing race tests and authenticated Redis-only
  failure, promotion, client redirection and recovery integration test.
- Docker build, non-root CLI smoke check, Helm lint and rendering.
- Updated source scans found no reachable vulnerable symbols or affected
  imported packages. The rebuilt gateway image has zero High/Critical
  findings and zero Alpine package findings with the database used for this
  review. One Unknown module-level OpenPGP advisory remains; OpenPGP is not
  imported by the gateway, and no scanner suppression was added.
- Redis 7.4.12 Alpine image scan found no vulnerabilities. Its Alpine 3.21
  base reaches ordinary support end on 2026-11-01 and needs a subsequent
  upstream image-base review.

See the [dependency review](../security/dependency-audit-2026-10-27.md)
for versions, advisory scope, remaining findings and deferred updates.

## Rollout

- Chart version, application version and default gateway image are `0.3.1`.
- No Redis key-schema migration or PVC reset is required. Preserve production
  resource and storage settings; this release does not resize volumes.
- Upgrading the chart also rolls Redis to 7.4.12 unless its image is overridden.
  Roll cores one at a time, preserving the Raft majority, and verify each
  replica is connected and synchronized before advancing. Pod readiness alone
  does not prove the local Redis replica is synchronized.
- Redis primary restart can interrupt service; asynchronous replication and
  the existing failover failure window still apply. This release does not
  guarantee lossless failover or repair malformed AOF files.
- Set `core.redis.replBacklogSize: "128mb"` explicitly for deployments needing
  the larger backlog, with RAM headroom. The compatibility default remains
  `"1mb"`.

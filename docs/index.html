Quick Start

# git clone https://github.com/keel-iot/keel-mqtt-gateway.git
# cd keel-mqtt-gateway
# docker-compose -f docker-compose.core-edge-split.yml up -d
# mosquitto_pub -h localhost -p 1883 -t "telemetry/device-1" -m "Hello Keel"

Core/Edge Architecture

Stateless edge nodes scale horizontally via HPA, while stateful core nodes maintain cluster state.

CP/AP Split

Raft for session ownership (Strong Consistency). Olric for routing (High Availability).

Direct gRPC Data Plane

Messages forwarded directly between edge nodes, bypassing control plane for low latency.

QoS Persistence

Redis co-located on core nodes (Primary+Replica) ensures message durability.

Kafka/Ditto Integration

Built-in connectors to forward telemetry to Redpanda/Kafka with Hono/Ditto schemas.

mTLS & Hot Reload

Native TLS termination with certificate hot-reloading. No pod restarts needed.
